## Selection Rules Reminder

Select only when at least one is true:

- [ ] User explicitly requested the area
- [ ] A requirement/constraint maps directly to it
- [ ] A selected skill declares it as a dependency
- [ ] Omitting it leaves a quality attribute or risk unaddressed
- [ ] An applicable quality gate requires it

Skipped skills must have a skip reason (e.g. "no AI requirements", "no UI surface").
