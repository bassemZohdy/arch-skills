# WCAG 2.2 verification reference

Pin the assessed edition, level, user journeys, technologies and evidence date.
Use the normative [WCAG 2.2 recommendation](https://www.w3.org/TR/WCAG22/) for exact
criteria and exceptions; this guide is not a complete conformance checklist.

## Scope and verification

Cover perception, operation, understanding and compatibility with assistive
technology. Pair automated findings with keyboard, screen-reader, zoom/reflow
and realistic task checks. Record criterion ID, affected flow, actual evidence,
severity and unresolved barriers. Conformance applies to the declared scope,
not merely to the components that passed a scanner.

## Changes to consider from 2.1

Assess added criteria: 2.4.11–2.4.13 (focus visibility/presentation), 2.5.7
(drag alternatives), 2.5.8 (target sizing), 3.2.6 (help consistency), 3.3.7
(repeated entry), and 3.3.8–3.3.9 (authentication accessibility).
Criterion 4.1.1 is removed in 2.2; retain edition-specific handling for 2.1
obligations instead of silently mixing versions.

## Contrast starting points

| Content | AA | AAA |
| --- | --- | --- |
| Normal text | 4.5:1 | 7:1 |
| Large text as defined by the standard | 3:1 | 4.5:1 |
| Applicable non-text controls/graphics | 3:1 under 1.4.11 | Same AA requirement; no blanket 4.5:1 rule |

Apply the normative exceptions and measurement rules. Determine required level
and legal applicability with the responsible authority; this reference does not
establish jurisdiction-specific obligations.
