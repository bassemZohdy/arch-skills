# DAP fixtures

Current fixtures are generated by `tests/dap_fixture.py`; no static records live
in this directory. Use `--suite --output <fresh-directory>` to create isolated
schema-2 create, interview, update, greenfield, brownfield, interrupted and
blocking-review workspaces. Every workspace contains `architecture/`.

All approval identities and semantic assessments are synthetic. The complete
greenfield fixture scores 100 and is ready; the security-review fixture also
scores 100 but remains blocked. Other incomplete fixtures retain explicit gaps.
The historical 76% example under `examples/greenfield` is schema 1 and is not a
current readiness demonstration. Deterministic fixture checks do not execute an
LLM or prove host behavior.
