# Architecture practice reference

This page routes readers to the maintained skill guidance. It is not a universal
checklist or a source of fixed service targets. Choose measurable thresholds,
review authority and applicable standards for the project and record their
source and owner in the architecture evidence.

| Need | Maintained guidance |
| --- | --- |
| Interview, create or update an architecture | [arch-orchestrator](../skills/arch-orchestrator/SKILL.md) |
| Architecture documents and views | [arch-doc](../skills/arch-doc/SKILL.md), [arch-diagrams](../skills/arch-diagrams/SKILL.md) |
| Design-quality review | [arch-review](../skills/arch-review/SKILL.md) |
| Process readiness and evidence | [arch-evaluate](../skills/arch-evaluate/SKILL.md), [DAP specification](deterministic-architecture-process.md) |
| Option analysis and decisions | [arch-decision](../skills/arch-decision/SKILL.md) |
| Performance and resilience | [arch-perf](../skills/arch-perf/SKILL.md), [arch-resilience](../skills/arch-resilience/SKILL.md) |
| Security, compliance and accessibility | [arch-security](../skills/arch-security/SKILL.md), [arch-compliance](../skills/arch-compliance/SKILL.md), [arch-accessibility](../skills/arch-accessibility/SKILL.md) |
| Verification and automated architecture checks | [arch-test](../skills/arch-test/SKILL.md), [arch-fitness](../skills/arch-fitness/SKILL.md) |
| Operations, observability and change | [arch-devops](../skills/arch-devops/SKILL.md), [arch-observability](../skills/arch-observability/SKILL.md), [arch-migration](../skills/arch-migration/SKILL.md) |

Each skill's description states when to use it; its `references/` files supply
detail when needed. The [boundary map](skill-boundaries.md) covers the other
specialists and handoffs. References and external standards in skill guidance
are supporting sources; check the applicable edition and organizational policy
before claiming conformity. A passing repository test validates the package,
not a project's architecture or compliance.
