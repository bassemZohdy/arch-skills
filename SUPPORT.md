# Support

Start with the [README](README.md), [skill testing guide](docs/skill-testing.md)
and [harness compatibility guide](docs/harness-compatibility.md).

For a reproducible bug, open an issue using the bug template and include the
operating system, Python version, package profile, command, expected result and
relevant output. Remove credentials and private architecture data before
sharing logs.

For a focused improvement, use the feature request template. Questions about a
real architecture baseline should omit confidential records and identify the
smallest public example that demonstrates the question.

Use the private process in [SECURITY.md](SECURITY.md) for suspected
vulnerabilities. Do not report security issues in public tickets.
