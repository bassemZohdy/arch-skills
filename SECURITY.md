# Security policy

Please do not disclose a suspected vulnerability in a public issue, pull
request or discussion.

Use GitHub's private vulnerability reporting or Security Advisories for this
repository. If that private channel is unavailable, contact the repository
maintainers privately through a channel associated with the repository and
include:

- the affected path, package profile or installed artifact;
- the smallest reproducible example;
- the impact and any prerequisites; and
- a suggested mitigation, if known.

This repository contains host-neutral instructions and deterministic validation
helpers. Do not include credentials, private architecture records or other
sensitive project data in a report. Public disclosure should wait until the
maintainers have had an opportunity to assess and address the issue.
